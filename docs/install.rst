============
Installation
============

.. raw:: html

   <h3>
       via <a href="https://pip.pypa.io/" target="_blank" rel="noopener noreferrer">pip</a>
   </h3>

.. code-block:: bash

   pip install -U aiopaysell

.. raw:: html

   <h3>
       via <a href="https://docs.astral.sh/uv/" target="_blank" rel="noopener noreferrer">uv</a>
   </h3>

.. code-block:: bash

   uv add aiopaysell

.. raw:: html

   <h3>
       via <a href="https://python-poetry.org/" target="_blank" rel="noopener noreferrer">Poetry</a>
   </h3>

.. code-block:: bash

   poetry add aiopaysell

.. raw:: html

   <h3>
       via <a href="https://pdm-project.org/" target="_blank" rel="noopener noreferrer">PDM</a>
   </h3>

.. code-block:: bash

   pdm add aiopaysell

FastAPI webhook support
------------------------

The FastAPI webhook manager needs the ``fastapi`` extra:

.. code-block:: bash

   pip install aiopaysell[fastapi]
